# BRO WIFI ZONE

Site officiel BRO WIFI ZONE - Internet CPE, Starlink, MikroTik, WiFi et services réseau.

## Déploiement

1. Uploader tous les fichiers sur GitHub.
2. Importer le repository dans Vercel.
3. Cliquer sur Deploy.

Le projet utilise Next.js 14 et Tailwind CSS 3 pour éviter les erreurs PostCSS/Tailwind v4.
